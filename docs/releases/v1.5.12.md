# S-UI v1.5.12

This release includes client setup improvements and installation/TLS configuration changes.

- New clients default to a `YYYYMMDDHHmm` name, 50 GiB traffic, one month of validity, and an IP limit of 3.
- Traffic plans suggest 3 months at 150 GiB, 6 months at 300 GiB, and 12 months at 600 GiB.
- Expiry dates can be entered directly, for example `26.11.6`; the current local time is retained.
- Fresh installs generate panel and subscription ports, let the administrator choose credentials, and can bind a domain with a certificate under `/root/cert/<domain>/`.
- Upgrades with existing data preserve settings and skip installer configuration prompts.
- The Settings page can fill panel and subscription TLS certificate paths for the selected domain.

No manual database migration is required.
